# ADR 0039: Wallpaper on Xfce

## Status

Accepted (2026-11-03).

## Context

Checked in a Xubuntu 26.04.1 live session (VirtualBox, Xfce 4.20,
xfdesktop 4.20.1, X11):

- loginctl gives `Desktop=xubuntu`, whose session file says
  `DesktopNames=XFCE`; `XDG_CURRENT_DESKTOP=XFCE`, also in the systemd
  user manager.
- xfdesktop keeps a picture for every monitor and workspace, in the
  xfconf channel `xfce4-desktop`, at
  `/backdrop/screen0/monitor<NAME>/workspace<N>/last-image`, where NAME
  is the output name `xrandr` shows (`Virtual-1`, `HDMI-1`). It reacts
  to changes at once.
- **Only pictures the user has changed are stored.** On a fresh system
  the channel has no backdrop property at all; the default comes from
  system files. The properties appeared only after the picture was
  changed in Desktop Settings.
- xfdesktop has no command to set the picture; `xfconf-query` is the
  documented way.

## Decision

On Xfce, Kisetsu sets, with `xfconf-query --create -t string`, every
`…/last-image` property that is:

- already in the channel (including monitors not connected now, so the
  picture is also right when they come back), and
- for each monitor from `xrandr --listmonitors` and each workspace
  (`/general/workspace_count` in the `xfwm4` channel, 1 if unknown).

Each value is a plain path and is read back, like gsettings values.
With no monitor and no existing property, it fails with a clear error
instead of guessing names.

## Consequences

- All monitors and all workspaces get the same picture, also when
  xfdesktop's "single workspace" option is on.
- Xfce on Wayland (experimental in 4.20) is not supported: monitor names
  from `xrandr` under XWayland do not match.
- The picture style (zoom, scale) stays as the user set it.

## Verification

Unit tests: existing and new properties for two monitors and two
workspaces, unrelated settings untouched, missing `xfconf-query`, no
monitors, a value that does not change, a failing command, recognition
through the Xubuntu session file. In the Xubuntu 26.04.1 live session
(2026-11-03), with the new `.deb` installed and a second workspace that
had never had its own picture: "Set as wallpaper", "Next wallpaper" and
the rotation timer changed the wallpaper on both workspaces.
